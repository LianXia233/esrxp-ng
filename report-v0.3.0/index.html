04

硬字幕抓取管线

与 esrXP 一致的 帧差 → 色彩过滤 → 后处理 → 分段 → 多格式输出；preview 缩放/锐化并入 ROI 预处理。

FFmpeg 解码
NVDEC/D3D11VA/VAAPI 硬件优先，CPU 回退；按 frame_skip 抽帧
→
帧差检测
pixel_difference 阈值 + ignore_change_percent 过滤变化帧，产出 changed_mask
→
色彩过滤
主色/描边色/附加颜色 + pixel_compensate；HSV 整数公式 + RGB int32 距离
→
后处理
连通域清理：single_dot / single_line / large_block / touch_edge / pass_center
→
IoU 分段
gap_frames 合并相邻字幕；force_merge 强制合并；自动选色
→
多格式输出
SSA · VobSub(.idx+.sub) · OCR PNG · SRT · SRT+bitmap · timeline.json · .esr
